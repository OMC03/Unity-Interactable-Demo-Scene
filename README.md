# Unity Interactable Demo
### Description
This is a repository containing a demo scene I made to learn about Unity's Interactable system capabilities. The structure of it is very bare bones, but it contains 
some intricate gameplay features, such as  locked doors, keycards, and basic character movement in a first-person perspective space.
